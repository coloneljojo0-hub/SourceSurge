# Source Surge

**Source Surge** is a total conversion built on the Source SDK 2013 (TF2 branch).

It overhauls movement, adds wave-based gameplay, competitive modes, and a variety of custom systems while keeping the fast, fluid feel of Team Fortress 2 as a foundation.

> **⚠️ Important**  
> This is **not** a finished product in any way.  
> Builds will very likely not work properly (or at all) right now — that is completely normal.  
> Expect crashes, missing features, broken systems, and frequent changes.  

---

## Features (current)

- Heavily modified movement system (ground strafe, momentum-preserving landings, air control tweaks, etc.)
- Slam mechanic
- Wave-based gameplay
- 1v1 mode
- Customizable speedometer & FPS counter
- Grappling hook (hitscan)
- Stats menu
- Multiplayer work-in-progress

More systems are planned as the foundation stabilizes.

---

## Running the game

1. Download the latest build / release
2. Launch `mod_tf_win64.exe` from the game folder
3. **Do not expect it to work properly.** Crashes, broken menus, missing assets, and incomplete systems are normal at this stage.
